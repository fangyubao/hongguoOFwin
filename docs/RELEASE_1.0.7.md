## 红果短剧 Windows 桌面版 1.0.7

电脑直接安装的桌面客户端，双击图标就能看，不依赖浏览器、不需要装 Node。

### 这版更新了什么

- **内容库从 800 部扩到 11,009 部**：内置完整索引随包分发，装完第一次打开就能搜索、看分类，不用等抓取。
- **自动更新内容库**：每 6 小时自动刷新官网分类并增量扩库；也可以在「文件 → 立即更新内容库」手动触发，列表标题旁会显示上次更新时间。
- **修复打包版无法播放**：Electron 内置的 BoringSSL 缺少 SM3 摘要，导致签名失败、点播放报错。这版自带纯 JS 的 SM3 实现，播放恢复正常（1080P 可取）。
- **搜索更稳**：以官网检索为主、本地索引兜底，遇到 5xx 自动重试 3 次，同一关键词 5 分钟内复用结果。
- **数据不丢**：索引写入改成「防抖 + 最多憋 20 秒必落盘」，长时间运行或强制退出都不会整轮白抓；老版本升级会自动把新索引合并进来。
- **显卡兼容**：GPU 进程崩溃后下次自动改软件渲染，白屏/打不开可直接用；「视图 → 使用硬件加速」可随时切回。

### 功能

搜索、分类标签、封面墙、详情、选集、上下集、自动连播、倍速、清晰度切换、全屏、观看历史、断点续播、收藏。
菜单里还能开启局域网访问，让电视/手机用浏览器打开同一台电脑上的内容。

### 安装

1. 下载 `HongguoTV-Setup-1.0.7.exe`；
2. **安装目录请改成非系统盘**（例如 `F:\HongguoTV`）；
3. 装完桌面会有「红果短剧」快捷方式。

> 为什么强调安装盘：客户端用便携模式，索引和缓存写在安装目录旁的 `data\`。装在默认的 `%LOCALAPPDATA%\Programs` 就会落到 C 盘；装到其他盘则完全不占系统盘。
